## What you're looking up

Your **public IP address** is the one websites and services see. It belongs to your internet connection, not to one computer, so every device on the same Wi-Fi usually shows the same address.

## Use the right network

The address changes with the network. Home Wi-Fi, mobile data, the office and a VPN each show a different one. **Look it up from the same network** the provider or support team asked about.

## IPv4 or IPv6

Many connections have both. An IPv4 address is four numbers with dots, like 203.0.113.25. An IPv6 address is longer, with letters, numbers and colons, like 2001:db8::25. When someone just asks for "your IP address", send the IPv4 one. If the site shows only one row, that is the only kind your connection has.

## Use the Copy button

Clicking the address itself opens a lookup page instead of copying it. The page also lists a city, postal code and your internet provider. These are estimates for your provider's network, so they are often a nearby city, and you don't need them.
